Access Levels

What each role can do

The Government Portal supports two access levels — Field Officers and Administrators. Both require verified BBMP credentials.

🌿 Field Officer

  • View and filter tree inventory
  • Run AI health scans
  • Log maintenance actions
  • View green cover map
  • Approve HITL flagged trees
  • AI assistant (officer mode)

🏛 Administrator

  • All officer capabilities
  • Add & edit tree records
  • Manage ward thresholds
  • View full AI metrics dashboard
  • Manage pending approvals
  • System configuration access

Authorised personnel only

This portal is restricted to BBMP officers and administrators. Use your government credentials to log in.
